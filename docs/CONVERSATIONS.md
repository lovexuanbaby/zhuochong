# 桌宠对话与 DSH 任务会话

本地 `0.2.3-rc.1` 开发功能，尚未提交或发布。重新启用链接插件后，打开桌宠对话框右上角 **会话**。

## 两种模式

### 桌宠对话

- 新建会保留原对话；下拉列表可选择以往对话，再点“切换”。
- “清空选中”只清空指定对话的消息；“删除选中”移除指定对话；“清空全部桌宠历史”清除当前和保存的桌宠对话。
- 删除在当前窗口内二次确认，不创建模态弹窗。保存失败保留旧记录；生成回复期间不允许切换或清空，防止迟到回复污染其他对话。
- 最多保留 20 个对话；达到上限会提示先删除旧对话，不会静默丢弃旧记录。
- 每个对话拥有独立消息上下文；长期记忆、事件记忆、陪伴状态、日报和表达偏好仍共享。清空聊天不是清除这些数据，也不是删除提供方数据。
- `chat-history.json` 仍保留顶层 `messages`，新增 `conversationId` 和 `conversations`；旧单对话文件可直接读取。归档字段由新版本维护，降级前应备份。

### DSH 任务

- 选择已有 DSH 工作区后点击“新建”，通过宿主 `sessionController.create` 创建真正的 DSH 会话。
- 会话列表可切换已有普通会话；发送使用官方 `prompt` 接口进入 Agent 队列，可执行该 DSH 配置允许的工具任务。工具权限和用户确认仍在 DSH 主窗口处理。
- 显示最近 100 条范围内的公开文本；不显示模型推理、工具原始输出或注入的运行时上下文。含编辑/删除事件的页面保守地交给 DSH 查看完整视图。
- “停止本轮”调用官方 cancel；不清空 DSH 已排队消息。切回桌宠模式或停用插件不会自动停止已经发起的 DSH 任务。
- “归档选中”通过 `workspaceController.archiveSession` 隐藏会话，**不等于删除**。正在运行的会话由 DSH 拒绝归档，需先停止工作。当前接口没有暴露永久删除操作，桌宠不直接改写 DSH 日志文件。
- 当前列表最多显示 100 个未归档普通会话；完整历史、归档恢复和复杂操作继续使用 DSH 主界面。

## 跨会话工作回顾

日报不是仅总结桌宠闲聊：它聚合插件启用后捕获的多个 DSH 会话任务。在桌宠模式直接说“总结今天的工作”“回顾昨天的任务”或“生成日报”，也会把对应日期已记录的任务概要交给当前模型总结。

普通聊天、否定请求和只是讨论日报功能时不会自动附加工作概要。旧 DSH 会话不会被自动扫描导入；选中旧会话阅读也不等同于将全部历史导入日报。

## 实现与验证范围

- DSH 适配仅调用已核对的宿主公开服务，不读取密钥、不启动第二个 Harness、不直接删除 DSH 存储。
- `tests/conversations-smoke.mjs` 使用临时文件与 mock 服务覆盖本地历史隔离/清理、并发保护、DSH 请求契约和跨会话回顾数据。
- `tests/conversations-ui-smoke.py` 验证模式路由、内嵌确认、失败恢复、迟到消息隔离与 Qt 窗口行为。
- 用户已在重启 DSH 后确认工作区和已有会话可见，并在选定工作区创建真实会话、发送只回复文本的请求；回复同时显示在桌宠与 DSH 主窗口。未对真实会话执行归档或永久删除验收。
- 自动化宿主/UI 测试使用临时数据、mock 服务与 fixture；没有清除或归档用户的真实记录。
