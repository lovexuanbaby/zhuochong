# 每日回顾与表达自优化（0.2.2 功能）

入口：桌宠对话框右上角 **日报**。本功能自 `v0.2.2` 起提供；`v0.2.1-rc.2` 及更早版本不包含它。

## 使用

1. 重载本地新版插件后，正常在 DSH 中进行工作。
2. 打开“日报”，立即查看本地汇总；可切换已记录日期。
3. 点击“模型生成回顾”，使用 DSH 当前模型润色所选日的任务概要。
4. 选择“更简洁／更多细节／更正式／更轻松”。偏好会逐级调整并保存，下次日报和桌宠聊天都会使用；“重置风格”恢复默认表达。

按天累计工作，不定时弹窗、不自动调用模型。打开日报不调用模型；模型生成使用 DSH 已配置的提供方。

## 简单编排与反馈闭环

**记录员 → 总结员 → 检查员 → 用户反馈 → 偏好更新 → 下次应用。**

- 记录员读取运行中 `session/event` 的任务边界、用户标题、公开回复文本与工具调用计数。
- 总结员提供本地模板；用户点击后最多调用一次已配置的模型。
- 检查员检查空输出、数据版本、表达偏好版本和保存结果，不冒充事实核查模型。
- 风格教练将明确按钮反馈变成两个有界偏好值，并保留最近 20 次反馈和更新版本。

这体现的是轻量 Agent 职责编排和受反馈驱动的自优化（RSI-lite 展示）：同一进程内按步骤执行，不新建多个 DSH agent，不修改代码，不训练模型权重，不宣称通用能力自动提升。不会仅凭模型自己的输出猜测用户偏好。

## 数据边界

- 只记录插件启用后捕获的 DSH 工作，不扫描历史会话文件，也不把桌宠闲聊自动当成已完成工作。
- 按 **Host 本地时区** 日界线、任务开始日期归档，最多保留近 30 天、300 个任务轮次。
- 会话标识保存为摘要；标题和回复摘录最多 180 字符。工具参数、原始工具结果和推理过程不进入日报文件；计数有上限，不当成审计日志。
- 点击模型生成时，只发送所选日最近 50 个任务的上述概要。模型仍可能总结不准确；“已结束”只代表 DSH 轮次结束，不代表成果经业务验收。
- 默认文件为聊天历史同目录下的 `daily-review.json`，本机明文原子保存。`chatDailyPath` 可覆盖路径，`chatDailyEnabled: false` 停止记录与偏好注入；已有文件不自动删除。
- 保存失败、模型失败、超时或版本变化会明确提示；不会用旧生成结果覆盖新偏好。关闭日报会取消当前模型请求。

## 验证

`tests/daily-review-smoke.mjs` 的 15 项检查覆盖来源筛选、并发、时区跨日、缓存、偏好持久化/重置、聊天提示应用、DSH 模型适配、生成竞态、超时取消、写入失败、停用和损坏文件。

`tests/daily-review-ui-smoke.py` 的 10 项检查覆盖入口、日期切换、模型请求、阶段显示、反馈版本、关闭取消、迟到响应、错误重试和空数据恢复。测试使用临时数据与 mock 模型，不触碰真实用户日报。
