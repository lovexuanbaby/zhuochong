## DSH 桌宠 0.2.0-rc.1

本版为 Windows 预发布版，沿用 DSH 中已配置的模型和凭据，不另起 Harness。

### 更新

- 将 agent 忙闲状态与任务结果分开显示，支持并发任务、中止恢复和运行中重载。
- 新增长期记忆查看、确认删除、刷新、超时和保存失败反馈；使用稳定标识与版本校验防止误删。
- 加入真正的 Schemastery 配置，支持解释器路径、聊天与记忆参数设置。
- 移除开发机固定 Python 路径，支持独立环境、环境变量及本机自动发现。
- 提供 setup/doctor 脚本，使用 PySide6 Essentials 6.12.0，补齐安装、诊断和数据保留说明。

### 安装

1. 下载 `dsh-deskpet-0.2.0-rc.1.tgz`，需要时用同目录 `.sha256` 文件核对。
2. 先安装 Python 3.10+，解压 tgz 后进入 `package` 目录，运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1`。
3. 通过 DSH 插件管理安装本地包，清除旧的解释器覆盖（如有），启用或重新加载插件。
4. 详细说明见包内 `docs/INSTALL.md`。

交付物不包含 Python 可执行文件；安装依赖需要网络。项目继续保留 `private: true`，本次通过 GitHub 发行附件交付，不向 npm 发布。

### 验证与数据说明

自动检查包括 Config 10 项、Host 24 项、Qt 聊天 36 项、桥接 8 项，以及状态转换、原生 Cordis 校验和 tgz 独立安装检查。用户于 2026-11-09 确认测试均通过，并授权提交与发布。

删除长期记忆不会删除聊天历史或提供方数据；原聊天仍可能参与当前回复。升级/卸载不会自动清除本地历史和画像，重要数据请自行保留。计时、提醒和独立 EXE 不属于本版功能。
