## DSH 桌宠 0.2.1-rc.2

本版为 Windows 预发布版，沿用 DSH 中已配置的模型和凭据，不另起 Harness。
相较 `0.2.1-rc.1` 功能未变，仅修复安装脚本在部分环境下不可用的问题。

### 本版修复

- 长路径判定改为读取系统 `LongPathsEnabled` 策略：策略已启用时，不再因为虚拟环境根目录超过 80 字符而拒绝安装；策略未启用时仍提前拦截并给出指引，避免装到一半才失败。脚本只读取该策略，从不修改注册表。
- `setup.ps1` 新增 `-PipIndex` 参数（或环境变量 `DSHPET_PIP_INDEX`）用于指定包源镜像。`PySide6-Essentials` 的 wheel 约 80 MB，弱网环境下默认源容易超时；依赖安装失败时，提示会直接给出镜像用法。
- 虚拟环境创建失败的提示补充为「确认所选解释器已安装 pip 与 venv 支持」，便于定位精简安装导致的失败。

### 更新（继承 0.2.1-rc.1）

- 将 agent 忙闲状态与任务结果分开显示，支持并发任务、中止恢复和运行中重载。
- 新增长期记忆查看、确认删除、刷新、超时和保存失败反馈；使用稳定标识与版本校验防止误删。
- 加入真正的 Schemastery 配置，支持解释器路径、聊天、记忆、计时和陪伴参数设置。
- 移除开发机固定 Python 路径，支持独立环境、环境变量及本机自动发现。
- 提供 setup/doctor 脚本，使用 PySide6 Essentials 6.12.0，补齐安装、诊断和数据保留说明。
- 新增加时/提醒命令、陪伴关系与情绪状态、低打扰主动关心、事件记忆。
- 修复超时/停用后孤儿用户消息、历史写入竞态、历史初始化竞态和空配置字段处理。

### 安装

1. 下载 `dsh-deskpet-0.2.1-rc.2.tgz`，需要时用同目录 `.sha256` 文件核对。
2. 先安装 Python 3.10+，解压 tgz 后进入 `package` 目录，运行
   `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1`。
   默认包源不可达时，追加 `-PipIndex <镜像地址>`，例如
   `-PipIndex https://pypi.tuna.tsinghua.edu.cn/simple`。
3. 通过 DSH 插件管理安装本地包，清除旧的解释器覆盖（如有），启用或重新加载插件。
4. 详细说明见包内 `docs/INSTALL.md`。

交付物不包含 Python 可执行文件；安装依赖需要网络。项目继续保留 `private: true`，通过 GitHub 发行附件交付，不向 npm 发布。

### 验证与数据说明

自动检查包括 Config 10 项、Host 聊天 25 项、Qt 聊天 39 项、桥接 8 项，以及 agent 状态转换、原生 Cordis 校验和候选 tgz 打包/清单检查。安装脚本的语法与注册表读取逻辑已在本机校验；另一台干净 Windows 上的从零安装仍待人工复验。

删除长期记忆不会删除聊天历史或提供方数据；原聊天仍可能参与当前回复。升级/卸载不会自动清除本地历史、画像、计时、陪伴或事件文件，重要数据请自行保留。独立 EXE 仍属于后续交付选项；当前使用可执行的 Python 环境方案。
