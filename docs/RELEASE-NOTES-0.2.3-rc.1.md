## DSH 桌宠 0.2.3-rc.1（未发布候选）

本版在 `0.2.2` 的基础上增加本地桌宠对话管理和真实 DSH 任务会话，仍沿用 DSH 已配置的模型与凭据，不另起 Harness。

### 更新

- 桌宠对话：新建、切换、清空、删除和清空全部，最多保留 20 个独立对话；长期记忆、事件、日报和表达偏好仍共享。
- DSH 任务：列出工作区和普通会话，新建会话，使用官方 `prompt` 队列发送，读取公开文字回复，停止当前轮，按官方接口归档。
- 归档只隐藏会话，不删除 DSH 原始历史；DSH 没有向桌宠暴露永久删除接口。
- 日报：记录插件启用后捕获的 DSH 任务概要，支持本地查看、显式模型总结和按钮式表达偏好反馈。
- 修复记忆删除面板关闭导致 Qt 应用退出的窗口生命周期问题。
- 继续使用真正的 Schemastery Config、独立 Python 环境安装/诊断和便携解释器发现。

### 验证

自动化结果：Config 10、Host 聊天 25、会话管理 11、日报 Host 15、聊天 Qt 40、会话 Qt 10、记忆窗口 7、日报 Qt 10、桥接 8；agent 状态逻辑通过。

真实 DSH 工作区/已有会话列表、新建会话和发送已有手动验收；**真实归档和永久删除尚未验收**。日报生成使用 mock 模型验证；真实模型日报仍属人工签收项。

### 安装与数据

安装方式同 `0.2.2`，详见 `docs/INSTALL.md`。聊天、记忆、计时、陪伴、事件、日报文件均为本机明文；停用或卸载不会自动删除这些文件或独立 Python 环境。`chatDailyEnabled: false` 可停止日报记录和表达偏好注入；已有文件不自动删除。

本候选包尚未提交或发布。发布前应清理旧 `dist` 产物，并在另一台干净 Windows 上完成安装验收。
