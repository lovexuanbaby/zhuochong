## DSH 桌宠 0.2.3

本版为 Windows 正式版，在 `0.2.2` 基础上新增本地桌宠对话管理和真实 DSH 任务会话，仍沿用 DSH 已配置的模型与凭据，不另起 Harness。

### 更新

- 桌宠对话：新建、切换、清空、删除和清空全部，最多保留 20 个独立对话；长期记忆、事件、日报和表达偏好仍共享。
- DSH 任务：列出工作区和普通会话，新建会话，使用官方 `prompt` 队列发送，读取公开文字回复，停止当前轮，按官方接口归档。
- 归档只隐藏会话，不删除 DSH 原始历史；DSH 没有向桌宠暴露永久删除接口。
- 跨会话工作回顾：在桌宠直接说「总结今天的工作」「回顾昨天的任务」「生成日报」，会把对应日期捕获的任务概要注入当前模型；普通闲聊、否定请求和仅讨论该功能时不会触发。
- 修复记忆删除面板关闭导致 Qt 应用退出的窗口生命周期问题。
- 继续使用真正的 Schemastery Config、独立 Python 环境安装/诊断和便携解释器发现。

### 安装

1. 下载 `dsh-deskpet-0.2.3.tgz`，用同目录 `.sha256` 核对。
2. 先安装 Python 3.10+，解压 tgz 后进入 `package` 目录，运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1`。
   默认包源不可达时追加 `-PipIndex <镜像地址>`，例如 `-PipIndex https://pypi.tuna.tsinghua.edu.cn/simple`。
3. 通过 DSH 插件管理安装本地包，清除旧的解释器覆盖（如有），启用或重新加载插件。
4. 详细说明见包内 `docs/INSTALL.md`，功能操作见 `docs/USER-GUIDE.zh-CN.md`。

交付物不包含 Python 可执行文件；安装依赖需要网络。项目继续保留 `private: true`，通过 GitHub 发行附件交付，不向 npm 发布。

### 从 0.2.2 升级

直接覆盖安装即可，现有聊天、记忆、日报和历史任务记录都会保留。旧版单对话的 `chat-history.json` 可直接读取。

**但降级有数据风险。** 本版开始由新版本维护 `conversationId` 和 `conversations` 两个字段。`0.2.2` 能读懂该文件，但写回时会丢掉 `conversations`，也就是你归档的多个对话。如果你可能退回 `0.2.2`，请先备份 `chat-history.json`。

### 验证

自动化结果（Windows，Python 3.14.6 / PySide6 6.12.0）：Config 10、Host 聊天 25、会话管理 11、日报 Host 15、聊天 Qt 40、会话 Qt 10、记忆窗口 7、日报 Qt 10、桥接 8，合计 11 个测试文件、136 项检查，退出码 0。

真实 DSH 工作区/已有会话列表、新建会话和发送已有手动验收；真实归档尚未验收，永久删除不属于桌宠支持的功能。日报生成使用 mock 模型验证；已有用户反馈真实使用时无法总结，原因尚未定位，本版不宣称已修复。另一台干净 Windows 上的从零安装仍未执行（本版安装脚本与 `0.2.2` 相同，未改动）。

### 数据说明

聊天、记忆、计时、陪伴、事件、日报文件均为本机明文；停用或卸载不会自动删除这些文件或独立 Python 环境。`chatDailyEnabled: false` 可停止日报记录和表达偏好注入，已有文件不自动删除。清空聊天不等于清除记忆、事件或日报，也不是删除提供方数据。
