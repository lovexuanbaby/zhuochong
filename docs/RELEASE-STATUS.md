### 记忆删除窗口修复（2026-11-19）

真实 Qt 事件循环复现了问题：原生删除确认框关闭后触发应用退出，虽然桌宠/聊天仍使用 Tool 窗口。原测试模拟了确认框返回值，未覆盖这个窗口生命周期问题。

- 改为记忆面板内部的“确认删除／取消”，不再创建模态弹窗；确认期间动画和桥接心跳继续运行。
- Host 管理的 Qt 应用不再因子窗口关闭自动退出；明确关闭桌宠本体、Host shutdown 或输入 EOF 仍会结束进程。
- 新增 `tests/memory-window-smoke.py`，以生产桥接和真实 Qt 事件循环验证 7 项生命周期场景；聊天 UI 40 项及其余现有回归全部通过。
- 当前 DSH 安装链接指向本工作区；停用再启用插件即可载入修复。本修复已包含在 `0.2.2` 中。
