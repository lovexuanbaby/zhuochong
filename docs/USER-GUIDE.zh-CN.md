# DSH 桌宠功能使用手册

适用于 DSH Desktop 中的 dsh-deskpet 插件。手册说明桌宠提供的功能、常用操作和数据边界；安装步骤见[安装说明](./INSTALL.md)，版本变化见[发行说明](./RELEASE-NOTES-0.2.2.md)。

## 1. 桌宠与模型

插件启动后会显示置顶桌宠。点击桌宠或在右键菜单选择“打开对话框”，即可打开聊天窗口；拖动窗口标题区域可移动窗口。关闭聊天窗口只会隐藏它，不会退出插件。

桌宠聊天使用 DSH 已配置的模型、提供方和凭据，不会创建新的 DSH Agent，也不需要单独配置 API 密钥。可在插件设置里同时填写 `chatProvider` 和 `chatModel` 固定路由；两项都留空时沿用 DSH 当前模型。`chatSystemPrompt` 可以覆盖桌宠的基础回复风格。

## 2. 桌宠对话

在对话框输入内容后按 Enter 或点击发送。最近聊天记录会保存在本机并在重启后恢复。桌宠对话是插件自己的聊天，不会出现在 DSH 普通会话列表中，也不会执行 DSH Agent 工具。

点击右上角“会话”，模式选“桌宠对话”，可以新建、切换、清空或删除选中的对话，也可以清空全部桌宠聊天历史。新建会保留旧对话。切换和删除在窗口内确认；生成回复时会暂时禁止切换/清空，以免迟到的回复写入错误对话。

清除桌宠聊天不会删除长期记忆、事件记忆、计时器、日报或 DSH 会话。长期记忆与聊天记录分开管理。

## 3. DSH 任务会话

点击“会话”，将模式切换为“DSH 任务”，刷新工作区和会话列表，然后选择一个工作区。点击“新建”会在 DSH 中创建真正的普通会话；选择已有会话后点击“切换”，即可在桌宠窗口查看和继续该会话。桌宠发送的提示进入 DSH 原生 Agent 队列，工具权限和审批仍由 DSH 管理。

“停止本轮”停止当前 Agent 轮次，不清除 DSH 已排队的输入。桌宠可显示公开文字回复和运行状态，不显示模型推理、注入上下文或原始工具输出。含编辑/删除记录的复杂历史请在 DSH 主窗口查看。

“归档选中”只把会话从普通列表隐藏，不是永久删除；归档恢复和永久删除请使用 DSH 主界面。切回桌宠模式或关闭桌宠窗口不会停止正在运行的 DSH 任务。

## 4. 记忆与个性化

### 长期记忆

默认每完成 4 轮桌宠聊天，插件会用 DSH 当前模型从近期聊天整理用户偏好、习惯、目标等摘要。摘要保存在本机，后续聊天可参考；右上角“记忆”可查看和删除单条记忆。

删除记忆不会删除原聊天记录，也不是提供方侧的数据删除。插件会避免从删除前的旧轮次重新提炼同一条记忆，但之后的新对话仍可能表达出相近的新事实。设置 `chatMemoryEnabled: false` 可停用自动提炼和注入；已有记忆仍可查看、删除。

### 事件记忆与情绪状态

事件记忆用于保存对后续对话有帮助的具体事件，并按相关性提供给桌宠；情绪状态根据聊天作轻量更新并随时间回落。分别由 `chatEventsEnabled` 和 `chatEmotionEnabled` 控制。它们是提示上下文，不是诊断或心理健康服务。

### 主动关心

开启 `chatProactiveEnabled` 后，桌宠可按 `chatProactiveLevel` 进行低频问候：`quiet` 最安静（默认），`balanced` 增加早安，`chatty` 还可能增加午间问候。主动提示有频率限制，不写入聊天记录。关闭该选项可完全停用。

## 5. 计时与提醒

在桌宠对话中可直接发送以下命令：

- `计时 5 分钟` 或 `倒计时 30 秒`
- `10 分钟后提醒我 喝水`
- `查看计时` 或 `提醒列表`
- `取消 #2`（编号以回复为准）或 `取消所有计时`

计时与提醒保存在本机，插件重启后恢复；到期时桌宠会提示。`chatTimerSound` 默认关闭，可按需要打开提示音。`chatTimerEnabled: false` 可停用此功能。

## 6. 日报与表达风格

日报记录插件启用后观察到的 DSH Agent 任务，不会回扫启用前的旧会话，也不把桌宠闲聊记作 DSH 工作。日常工作在 DSH 会话中完成后，打开桌宠右上角“日报”，选择日期即可查看本地汇总；点击“模型生成回顾”才会调用一次 DSH 当前模型润色。没有任务记录时，模型不会被调用。

也可以在桌宠对话模式明确请求“总结今天的工作”“回顾昨天的任务”或“生成日报”，桌宠会使用已记录的任务概要回答。若日报为空，先确认插件启用后是否运行过新的 DSH 任务，再点“刷新”。模型润色失败时，页面会显示错误；本地汇总仍可查看。

日报可记录任务标题、公开回复摘要、结束状态和工具调用计数，不保存推理、工具参数或原始工具结果。内容最多使用所选日期最近 50 项概要。截图中类似“6 次工具调用”的数字是 DSH 任务事件统计，不代表日报按钮自行调用了工具。

日报下方的“更简洁”“更多细节”“更正式”“更轻松”会逐步保存你的明确偏好，之后用于日报和桌宠回复；“重置风格”恢复默认值。这是提示偏好调整，不训练模型权重、不修改程序，也不会自动提升 DSH Agent 的工具能力。详细说明见[日报与表达偏好](./DAILY-REVIEW.md)。

## 7. 本地数据与隐私

插件默认把数据写入 DSH 用户数据目录下的 `deskpet` 文件夹。聊天、长期记忆、计时、陪伴、事件和日报分别保存在独立 JSON 文件中；可用对应的 `*Path` 配置项覆盖路径。文件以本机明文保存，不加密。定期备份整个数据目录可以保留桌宠状态。

聊天消息及生成摘要会发送给 DSH 当前配置的模型。日报模型生成只发送有限的任务标题、公开回复摘要、状态和工具计数。插件不读取 DSH 密钥文件，不扫描 DSH 历史日志，不会因为清除桌宠聊天而删除 DSH 会话。停用或卸载插件不会自动删除本地数据。

## 8. 常用设置

| 设置 | 默认值 | 作用 |
|---|---:|---|
| `chatHistoryMessages` | 40 | 单次桌宠回复使用的近期消息数 |
| `chatHistoryMaxMessages` | 200 | 本地保留的桌宠聊天消息数 |
| `chatMemoryEnabled` | true | 启用长期记忆整理与注入 |
| `chatMemoryUpdateEveryTurns` | 4 | 长期记忆整理频率 |
| `chatEventsEnabled` | true | 启用事件记忆整理与召回 |
| `chatEventUpdateEveryTurns` | 4 | 事件记忆整理频率 |
| `chatEmotionEnabled` | true | 启用轻量情绪状态 |
| `chatTimerEnabled` | true | 启用计时和提醒命令 |
| `chatProactiveEnabled` | true | 启用低频主动关心 |
| `chatProactiveLevel` | quiet | 主动关心频率档位 |
| `chatDailyEnabled` | true | 记录新 DSH 工作并启用日报/风格反馈 |

Python、模型超时和存储路径等全部配置见 DSH 插件设置。安装、更新、Python 诊断和数据清理步骤见[安装说明](./INSTALL.md)。

## 9. 功能边界

- 桌宠闲聊与 DSH Agent 会话是两种模式：前者不调用工具，后者使用 DSH 原生会话与权限。
- 日报只能总结插件运行期间捕获到的信息，不能恢复未记录或已经清理的历史。
- 工具调用次数不代表任务成功或结果已经业务验收。
- 记忆、情绪与偏好是有限的本地辅助信息，不保证完全准确；重要事实请及时纠正或删除。
